# Zooming and Panning in the Blazor Maps Component

## Overview

This sample demonstrates zooming and panning functionality using the Syncfusion [Blazor Maps](https://www.syncfusion.com/blazor-components/blazor-map) component in a hosted Blazor WebAssembly application. The implementation focuses on map navigation features that allow users to explore geographic data efficiently through zoom operations and panning interactions. The sample also demonstrates customization of zoom behavior, toolbar options, and navigation settings that improve the user experience when working with large or detailed map datasets.

**Example**: https://blazor.syncfusion.com/demos/maps/zooming?theme=bootstrap5  

**Documentation**: https://blazor.syncfusion.com/documentation/maps/user-interactions#zooming  

## Key Features

- Demonstrates zooming functionality within the Syncfusion Maps component.
- Shows how map panning can be enabled for navigating zoomed regions.
- Demonstrates interactive map navigation through built-in zoom controls.
- Shows how zoom toolbar options can be configured and customized.
- Demonstrates different zooming modes supported by the Maps component.
- Illustrates map interaction settings for inspecting geographic regions in greater detail.
- Uses map navigation features to move across displayed map areas without reloading data.
- Demonstrates toolbar-based zoom management and user interaction workflows.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `ZoomingPanning.sln`

3. Restore NuGet packages.
4. Set the startup project 
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root or startup project directory.

```bash
dotnet restore
dotnet run
```
